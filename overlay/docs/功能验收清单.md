## 证据如何理解

- “具体断言通过”：报告明确执行了列出的输入并核对结果；适用范围以报告为准。
- “隔离测试通过”：使用临时目录、受控进程或接口替身验证指定分支；有替身的报告不能代替真实 Windows 客户端或原生平台测试。
- “证据核对通过”：代码、配置、文件元数据或既有报告核对，不能自动等同现场交互测试。
- “直接计时”：存在对应操作与输入的时间观测。单候选观测、历史版本观测、正式前后对照仍须区分；本标签本身不是“性能通过”。
- “同族代表计时”：测过相关底层操作，当前行没有独立计时；不同快捷键入口仍需各自的正确性证据。
- “仅操作阶段计时”：真实执行了该功能的部分阶段，例如文件层恢复或断点持久化；未包含的客户端传输、picker选择、重启等仍未计时。
- “不适用”：该行要求的是内容、版本或一致性约束，没有可单独计时的交互操作；仍需完成其静态或功能验收。
