## 已修正的问题

- 使用示例改为实际安装/项目路径占位，不再要求用户存在开发机的家目录、旧 PID 或已释放的云主机。
- 当前全量包已包含的功能不再要求执行历史小补丁安装器；更新与回退改为独立目录方式。
- `.clangd` 与 `ASTRO_CLANGD_CDB_DIR` 的作用、优先级和重启要求保持一致；索引线程数明确受 CPU 上限限制。
- 区分侧栏搜索的文件类型筛选与 Ctrl+Shift+F 的独立搜索入口。
- 区分本轮C110/1.0.8候选归档与未验收状态、上一轮1.0.4冻结记录与1.0.1 / 1.0.2 / 1.0.3历史测试；旧协议仍运行时不能按新协议多窗口处理。
- 明确 1.0.4 的命令结束事件只会重新检查标题，远端常驻 shell、旧客户端或事件缺失时保留 150 ms 兜底；不承诺所有 SSH 用法都获得相同退出加速。
- 明确 `:q` 关闭当前子窗口，整体退出用 × 或 `:qa`；未保存内容先按提示处理。
- 历史性能数字注明日期及版本范围，不能作为最新 ARM 版本的实机性能验收。
- 更正“错误门禁干净”等过宽声明，保留操作断言，同时明确旧门禁遗漏Windows Output、新EPERM阻断及关闭错误的证据边界。
- 原始测试 JSON、运行日志和临时截图不装入总包；包内链接指向整理后的说明和最终报告。
- 分开记录 Neo-tree 旧树窗口错误和扫描乱序问题；注明各自修前失败、定向通过数量、完整 CRUD 已通过及性能仍待签收的范围，保留原压力脚本的后续失败。
- 维护说明列出 AstroUI 折叠、Neo-tree 跟随、扫描代次及异步 ignored 查询等本地插件修改；依赖清单记录两处新修改的旧包/冻结摘要，避免插件更新覆盖后仍沿用原包的验收结论。
- 打包说明明确 Python 字节码缓存和 Git reflog 排除，Python 源码与 Git 对象/引用/配置/索引保留；归档过滤不删除安装目录里的原始运行数据。
