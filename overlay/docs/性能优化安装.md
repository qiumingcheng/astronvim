# 当前总包的安装与更新

本次C110/Windows1.0.8收尾候选完整包位于 `D:/mygenppt/nvim/candidates/closeout110-20261027/`，分别为 `astronvim-linux-x86_64.tar.gz` 和 `astronvim-linux-aarch64.tar.gz`，附SHA256。包含最后的CDB环境配置补丁、Select复制/剪切修复、配套VSIX及使用文档，运行日志和测试中间结果不入包。包是可部署的完整候选，不表示未关闭的性能、平台与其他验收项已通过。

## 新安装

选择与 Linux 机器相同架构的压缩包，解压到独立目录：

```bash
tar -xzf astronvim-linux-对应架构.tar.gz -C /目标目录
source /目标目录/astronvim/env.sh
astro-check
astronvim /项目目录
```

要求 Linux、glibc ≥ 2.34、Bash 和基础系统命令；项目的编译器、SDK、调试符号和目标程序依赖由项目准备。ARM 的当前实机验证状态见 [最终验收报告](最终验收报告.md)。

SSH 会话中，候选 `env.sh` 在调用者未设置 `NVIM_NOTTYFAST` 时自动启用 Neovim 的非快速启动策略，避免同步背景色探测等待；已有变量值（包括空值或 `0`）保留，`astro_deactivate` 恢复原环境。默认暗色主题和真彩色保持启用，不关闭其他终端查询。如需明确恢复快速探测，在 source 后执行 `unset NVIM_NOTTYFAST`。该环境策略与关闭流程分开验收：无录屏包装的真实 Windows 直接 SSH 启动后，正常关闭 VS Code 已验证远端进程退出和设置精确恢复；断网、强杀及其他环境不在此结论内，见 [验收报告](最终验收报告.md)。

## 更新与回退

退出旧版后，将新包解压到一个新的空目录，保留旧目录用于回退。按需合并自己修改的 `env.sh` 和线程过滤配置，避免直接覆盖个人设置。项目断点按项目路径保存在旧目录的 `state/nvim/breakpoints/`；需要保留时，在编辑器都退出后复制该目录到新安装的对应位置。

运行 `source 新安装目录/env.sh` 后重新启动。回退时退出新版、source 旧目录的 `env.sh`，再启动旧目录的程序。两种目录的原生二进制不能混用。历史补丁安装器的备份只适用于当时匹配的文件版本，不用于回滚当前总包。

Windows VS Code客户端首次安装或升级时，安装配套 `vscode/astronvim-terminal-keys.vsix`，当前冻结候选为1.0.8；步骤见 [客户端集成](../vscode/README.md)。当前110共同载荷与108 VSIX已装配为双架构完整候选，源码及CDB补丁均纳入归档核对。61f2 KeyStore路径优化仍未纳入。以后迁移Linux只需解压与source，SSH不会自动安装Windows扩展；旧 `install.py` 仅合并快捷键，不能替代VSIX安装。

归档工具的候选发布限制已通过 r6 小型双架构夹具验证：未验收候选不能覆盖正式交付，普通构建仍拒绝未完成的验收标记。该结果不是总包已发布，也不增加用户部署步骤；具体范围见 [验收报告](最终验收报告.md)。

## 插件更新与本地修改

默认关闭自动更新。`config/nvim/lazy-lock.json` 记录上游插件版本，但不能单独表示包内的本地修改；完整共同源码以 `source-manifest.json` 为准。执行 `:Lazy update`、重装插件或切换版本前，先保留当前完整安装目录，并核对涉及的本地修改。更新后须重新验证功能和性能，不要把原包的验收结果直接用于更新后的插件。

下列修改需要特别保留；表中插件路径均相对于 `data/nvim/lazy/`：

| 插件与文件 | 维护时应保留的行为 |
| --- | --- |
| `AstroNvim/lua/astronvim/plugins/toggleterm.lua` | 109 保留的 gdu 查询去重：单次 opts 复用检测结果，换用回退命令时才再查；下次 opts 重新检测，不跨调用缓存 PATH 或命令可用性 |
| `astroui/lua/astroui/folding.lua` | 先检查当前缓冲区是否启用 Treesitter，再查询解析器，避免已停用语法解析时逐行重复查询 |
| `neo-tree.nvim/lua/neo-tree/sources/filesystem/init.lua` | 重开侧栏时不读取旧树缓冲区的光标，继续扫描并在新树上跟随当前文件 |
| `neo-tree.nvim/lua/neo-tree/sources/filesystem/lib/fs_scan.lua` | 整树扫描记录代次，在完成和渲染前拒绝过期结果；ignored 缓存未就绪时等待本轮异步查询完成，保留同代次不同目录展开、关闭后失效和回调只执行一次的语义 |
