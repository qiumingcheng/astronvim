主使用方式为Windows VS Code＋配套客户端扩展＋PowerShell/SSH＋对应架构Linux包。Linux端解压、source即用；Windows扩展只在客户端首次安装或升级。本次按约定的四项进行收尾，当前组合为Linux C110与Windows客户端1.0.8。维护操作5项已完成固定8组耗时/CPU/内存对照，真实VS Code链路的45项核心与10项剪贴板端点分别完成固定8组采集；核心前两组复用相同源码与测量脚本的已成功记录。其中52个端点有可比较数据，旧版不支持调用栈单击刷新，以及已复现的Select复制/剪切错误，均单独保留，不将失败耗时与修复后成功耗时比较。本轮核心对照有3个耗时指标出现待复核的正向信号。五项既有成本差异、两项历史搜索信号及右键菜单偶发问题未关闭，ARM/EulerOS/手机缺少本轮实机证据。总包保持明确的未验收候选身份，不宣称全功能、全平台性能无劣化或商用验收通过。 历史测试保留原版本范围，见 [最终验收报告](最终验收报告.md)。
