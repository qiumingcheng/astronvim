# 源码小包安装

`astronvim-source.tar.gz` 只包含定制源码、固定版本清单、补丁、VS Code 扩展源码与文档。首次安装需联网和本机 C/C++ 构建工具；不是解压即可直接运行的完整二进制包。

```bash
tar -xzf astronvim-source.tar.gz
cd astronvim-source
bash install.sh --prefix /home/yourname/programs/astronvim --jobs 2
source /home/yourname/programs/astronvim/env.sh
astro-check
astronvim /path/to/project
```

同一个源码小包支持 Linux x86_64、aarch64，安装必须在对应架构运行，不支持交叉编译。Linux/glibc 最低 2.34；具体 C/C++ 编译器及系统前提、源码回退选项见源码包根目录 `README.md`。

`dependencies.lock.json` 固定下载 URL、版本和 SHA256；插件及解析器固定完整 Git 提交。下载失败不会自动升级版本；源码构建使用相同固定版本。Rust 使用 `--locked`，npm 使用 `ci`。补丁前后内容都核对 SHA256。

日志在安装目录 `.installer/logs`，错误历史在 `.installer/events.jsonl`。下载缓存、构建目录和续装状态也在 `.installer`；重复原安装命令可继续。不要在已存在的旧版安装目录上混装新版，应选新目录验证后切换。

安装完成后可运行 `astro-pack <安装目录外的文件.tar.gz>` 生成含全部依赖的离线包；构建缓存和运行日志不会打包。复制到另一台**同架构、兼容 glibc** 的 Linux 主机后 source 新目录的 `env.sh` 即可使用。不应在较新 glibc 上构建后承诺兼容较旧 glibc。

Windows 本地 VS Code 扩展仍需在客户端安装一次。安装器会从源码生成 `vscode/astronvim-terminal-keys.vsix`，版本 1.0.9；详见[客户端说明](../vscode/README.md)。Linux 侧不全局安装扩展、不修改用户 shell 配置。
